# Мой ритм — Дневник состояния между встречами

Веб-приложение для мониторинга динамики состояния участников закрытой терапевтической группы гипнотерапевта **Дениса Казакова** (3–5 человек), с поддерживающим ИИ-ассистентом для пациентов и аналитической сводкой перед очными встречами.

---

## 🌟 Возможности приложения

### 1. Для участников (пациентов):
- **Бережная авторизация:** вход по имени и паролю, либо через **ВКонтакте (VK ID)**.
- **Первичная анкета:** фиксация исходного запроса, целей и 4 базовых шкал от 1 до 10.
- **Еженедельный чек-ин (3-4 минуты):** краткая фиксация событий недели, инсайтов и 4 шкал:
  - 🌊 **Тревожность** (1 = полное спокойствие, 10 = острая тревога / паника)
  - 🌙 **Качество сна** (1 = бессонница, 10 = глубокий сон)
  - 🌿 **Настроение** (1 = подавленность, 10 = подъем и радость)
  - ⚡ **Уровень энергии** (1 = истощение, 10 = полон ресурса)
- **ИИ-ассистент поддержки:** тёплый, персонализированный отклик (2–4 предложения) по имени и на «вы», без нравоучений и диагнозов.
- **Интерактивный график «Мой ритм»:** плавная кривая сплайнов динамики за все недели.
- **Протокол психологической безопасности:** при упоминании триггерных кризисных слов система немедленно выводит контакты Дениса (+7 902 802-82-46, WhatsApp) и телефон экстренной линии доверия 8-800-2000-122.

### 2. Для ведущего терапевта (Дениса Казакова):
- **Сводный кабинет группы:** список участников, количество чек-инов, индикаторы динамики.
- **Приоритетные алерты безопасности:** мгновенное выделение сообщений с кризисными маркерами на первом плане.
- **Досье участника:** исходная точка (с чем пришёл, запрос, стаж), сравнительный график динамики, хронология всех еженедельных ответов.
- **✨ ИИ-сводка перед сессией:** автоматическая аналитическая выжимка ключевых изменений и фокуса внимания для очной встречи с кнопкой копирования в заметки.
- **Панель настроек и бэкапов:** ввод ключей anymodel.org, экспорт всей базы в JSON, импорт и сброс данных.

## 🚀 Быстрый старт (проверка прямо сейчас)

Приложение полностью автономно и работает без сложных сборщиков (чистый современный HTML5, CSS3, ES-модули и Chart.js).

### Запуск в браузере:
1. Сервер запущен на локальном порту:
   👉 **[http://localhost:8085/](http://localhost:8085/)**
2. Либо просто откройте файл `index.html` двойным кликом в любом браузере (Chrome, Safari, Edge, Яндекс).

### Тестовые аккаунты для быстрой проверки:
На экране входа раскройте блок демо-входа:
- **👤 Участник (Анна):** 3 недели чек-инов с видимой динамикой снижения тревоги и нормализации сна.
- **🩺 Ведущий (Денис):** доступ ко всем участникам группы, графикам, сводке всей группы и генератору ИИ-аналитики.
- **Новая регистрация:** введите любое новое имя и пароль, чтобы протестировать первичную анкету с нуля.

## 📱 Установка на телефон (PWA для iPhone и Android)

Приложение работает как полноценное мобильное приложение (**Progressive Web App**): без комиссий, без скачивания из App Store, с мгновенным запуском прямо с экрана телефона.

### Инструкция для участников на iPhone (iOS):
1. Откройте ссылку на приложение в браузере **Safari**.
2. В нижней панели Safari нажмите значок **«Поделиться»** (квадрат со стрелочкой вверх `⎋`).
3. Выберите пункт **«На экран "Домой"»** и нажмите «Добавить».
4. На рабочем столе появится иконка **«Мой ритм»**. Приложение запускается на весь экран, точно как из App Store!

### Инструкция для участников на Android:
1. Откройте ссылку на приложение в **Chrome** или **Яндекс Браузере**.
2. Браузер автоматически покажет плашку **«Установить "Мой ритм"»** (либо нажмите три точки `⋮` в меню браузера → *«Установить приложение»*).
3. Нажмите «Установить» — иконка появится среди приложений вашего смартфона.

   ```bash
   git commit -m "Add Moy Ritm therapy app"
   git push origin main
   ```
2. В настройках репозитория на GitHub перейдите в **Settings → Pages** и укажите ветку `main` (папка `/root`).
3. Приложение мгновенно станет доступно по постоянной ссылке в интернете!

## 🔒 Конфиденциальность и безопасность

- В режиме по умолчанию данные сохраняются в изолированном локальном хранилище браузера (`LocalStorage`).
- Предусмотрен экспорт и импорт в JSON через панель настроек терапевта.
- При подключении Firebase данные передаются строго по защищенному протоколу HTTPS.
- Кризисный протокол срабатывает на клиенте даже при полном отсутствии интернет-соединения, гарантируя безопасность участников в экстренной ситуации.
